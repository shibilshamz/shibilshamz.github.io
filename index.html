How I work

A simple process, built for handover

01

Map the manual work

I sit with the actual steps — who touches what, where the data lives, which failures already happen. Automation that ignores the failure paths breaks in week two.

02

Build it on infrastructure you own

Python or n8n on a VPS, containerised, behind a proxy with TLS. Tests where the logic is risky, structured logs everywhere, no dependency you can't inspect.

03

Document it and hand it over

Runbook, environment file, and a written description of every node or module. From the lab I keep one habit above all: if it isn't documented, it didn't happen.
